How to upload invoices:

Prepare a CSV file with the following columns:

  • invoice_number (required) — unique invoice ID
  • vendor_code — vendor identifier
  • vendor_name — vendor display name
  • amount — numeric invoice amount
  • invoice_date — format YYYY-MM-DD
  • due_date — format YYYY-MM-DD (optional)
  • currency — e.g., USD, EUR (optional, defaults to USD)
  • description — free text (optional)

Duplicate invoice numbers are skipped automatically.
