What is this app?

The Accounts Payable Invoice Anomaly Detector helps finance teams identify suspicious or unusual invoices before payment. It uses AI-powered analysis and rule-based checks to flag potential issues such as:

  • Unusually large amounts compared to vendor history
  • Potential duplicate invoices
  • Date anomalies (past-due at creation, unusual timing)
  • Negative amounts or other data quality issues
2

Prerequisites

To get the most out of this app, you will need:

  • Invoice data in CSV format (or manual entry)
  • A Kindo API key for AI-powered analysis (optional — rule-based detection works without it)
  • A modern web browser (Chrome, Firefox, Edge, or Safari)

Default login credentials: admin / admin. Change your password after first login.

3

Add Your First Invoices

There are two ways to add invoices:

  • CSV Upload: Go to Upload CSV and upload a file with columns: invoice_number, vendor_code, vendor_name, amount, invoice_date, due_date, currency, description.
  • Manual Entry: Go to New Invoice and fill in the form.
4

Run Anomaly Analysis

Once you have invoices loaded:

  • Go to any invoice detail page and click Run Analysis to analyze a single invoice.
  • Go to the Anomaly Analysis page and click Analyze All Pending to scan all pending invoices at once.

The system compares each invoice against the vendor's historical patterns to detect outliers.

5

Review and Resolve

When anomalies are detected:

  • Review the anomaly description and recommendation on the invoice detail page.
  • Change the invoice status to Approved or Rejected based on your review.
  • Mark anomalies as Resolved once addressed.
6

Next Steps

  • Set up a Kindo API key and agent for more accurate AI-powered detection.
  • Import your production invoice data via CSV.
  • Use the ? button on any page for context-specific help.
